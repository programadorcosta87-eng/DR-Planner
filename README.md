# DR PLANNER — Meu Orçamento

Aplicativo de controle financeiro pessoal para gerenciar receitas e despesas.


---

## 📋 Sobre o projeto

O **DR Planner — Meu Orçamento** é um aplicativo desenvolvido para facilitar o controle das finanças pessoais de forma simples, rápida e acessível.

A aplicação permite registrar receitas e despesas, organizar os lançamentos por categorias, acompanhar períodos específicos e visualizar os gastos de maneira mais clara.

Um dos principais objetivos do projeto é permitir que o usuário tenha controle das próprias informações diretamente no navegador, sem depender de um cadastro obrigatório ou de uma infraestrutura complexa.

---

## ✨ Funcionalidades

* Cadastro de receitas e despesas por categoria
* Visualização por mês ou período personalizado
* Meta de poupança
* Gráfico de gastos por categoria
* Exportar e importar dados (backup em JSON)
* Funciona 100% no navegador
* Progressive Web App (instalável no celular e computador)
* Interface responsiva
* Organização dos dados por períodos
* Visualização simplificada da situação financeira

## 🎯 Objetivo do projeto

O DR Planner foi criado com foco em usabilidade e praticidade.

A aplicação busca transformar o controle financeiro em uma experiência simples, permitindo que o usuário registre seus movimentos financeiros e tenha uma visão geral de suas receitas, despesas, categorias e metas.

O projeto também demonstra a construção de uma aplicação web com componentes reutilizáveis, gráficos, gerenciamento de dados e suporte a PWA.

---

## 🔐 Armazenamento

A proposta do projeto é trabalhar diretamente no navegador, permitindo que o usuário tenha acesso aos seus dados localmente.

O recurso de exportação e importação em JSON permite criar e restaurar backups dos dados utilizados pela aplicação.

---

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/programadorcosta87-eng/DR-Planner.git
```

### 2. Entre na pasta

```bash
cd DR-Planner
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npm run dev
```

O projeto utiliza a porta `3000` em desenvolvimento.

Acesse:

```text
http://localhost:3000
```

## 📦 Build para produção

```bash
npm run build
```
